# 🤖 Focus Dashboard: Android Port

This folder is dedicated to the mobile version of the Focus Dashboard.

## 🏁 How to Start
As per the roadmap, we recommend using **Flutter** for the best UI fidelity.

### 1. Project Setup
If you have Flutter installed, run:
```bash
flutter create .
```
within this directory.

### 2. Logic Translation
The core logic from `../logic.py` needs to be ported to Dart classes in `lib/`.

## 📂 Structure
- `lib/`: Dart source code.
- `assets/`: Icons, themes, and sound files for mobile.
- `android/`: Native Android configuration.
